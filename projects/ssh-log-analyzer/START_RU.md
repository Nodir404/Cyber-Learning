# Первый запуск в VS Code

Цель первого занятия — запустить программу, понять подсчёт и самостоятельно
изменить учебные данные. Первая версия уже подготовлена как основа для разбора.

## 1. Открой проект

Если репозиторий ещё не скачан, выполни в терминале Ubuntu:

```bash
git clone https://github.com/Nodir404/Cyber-Learning.git
cd Cyber-Learning
code .
```

Если он уже скачан, открой его папку в VS Code, открой встроенный терминал и выполни:

```bash
git switch main
git pull --ff-only origin main
```

Если команда `code` недоступна, открой VS Code обычным способом и выбери
File → Open Folder → Cyber-Learning.

## 2. Запусти учебный пример

В терминале из корня репозитория:

```bash
python3 --version
cd projects/ssh-log-analyzer
python3 analyzer.py data/sample_auth.log --csv report.csv
```

Нужен Python 3.10 или новее. Ожидаются **3 успешных входа, 4 неудачных,
4 IP-адреса и 3 пропущенные строки**. Рядом появится `report.csv`.
В примере вымышленные записи; они подходят для экспериментов.

## 3. Разбери одну запись

Открой `data/sample_auth.log`. Найди строку с `Failed password`, адресом
`192.0.2.10` и пользователем `admin`. В `analyzer.py` посмотри функции
`parse_line()` и `analyze()` и проследи:

1. Как из текста получается пара «IP, результат»?
2. Зачем проверять IP через `ipaddress`?
3. Где создаются два счётчика для нового адреса?
4. Какая строка увеличивает нужный счётчик?

## 4. Проведи свой эксперимент

Добавь в конец учебного лога ещё одну строку `Failed password` для `192.0.2.10`,
изменив время и номер процесса. До запуска предскажи новые результаты.
Запусти программу ещё раз и проверь: неудачных попыток должно стать **5**,
а уникальных IP по-прежнему **4**.

После этого удали добавленную строку и сохрани файл, чтобы вернуть исходный пример.
Проверь программу:

```bash
python3 -m unittest -v
```

## Следующая задача

Самостоятельно добавь вывод доли неудачных попыток в процентах:

```text
failed / (success + failed) * 100
```

В исходном примере получится примерно **57.1%**. Для пустого лога не должно
возникать деления на ноль. Это следующий небольшой шаг после первого запуска.

Для знакомства с проверкой частых неудачных попыток переходи ко
[второму занятию](LESSON_02_RU.md).
